## Day03 C# 条件分支

### 一、运算符（关系 + 逻辑，分支判断基础）

#### 1. 关系比较运算符

| 符号                                                         | 含义     | 返回值 | 示例              |
| ------------------------------------------------------------ | -------- | ------ | ----------------- |
| `>`                                                          | 大于     | bool   | `10 > 5 → true`   |
| `>=`                                                         | 大于等于 | bool   | `8 >= 8 → true`   |
| `<`                                                          | 小于     | bool   | `3 < 1 → false`   |
| `<=`                                                         | 小于等于 | bool   | `2 <= 5 → true`   |
| `==`                                                         | 相等判断 | bool   | `"123"=="123"`    |
| `!=`                                                         | 不相等   | bool   | `10 != 20 → true` |
| 核心：所有关系运算结果只有 `true/false`，用于if、switch条件。 |          |        |                   |

#### 2. 逻辑运算符（多条件组合）

| 符号 | 名称           | 规则                     | 短路特性                        |
| ---- | -------------- | ------------------------ | ------------------------------- |
| `&&` | 逻辑与（并且） | 两边全true才为true       | 短路：左边false，右侧代码不执行 |
| `    |                | `                        | 逻辑或（或者）                  |
| `!`  | 逻辑非（取反） | true变false，false变true | 无                              |
| `&`  | 非短路与       | 两边全true才为true       | 无论左边结果，两边都执行        |
| `    | `              | 非短路或                 | 任意一边true即为true            |

#### 真值速记

- `&&`：一假全假；`||`：一真全真；`!`：反转布尔值

### 二、if 分支语句（最常用多条件判断）

1. #### 三种基础if结构

1. **单分支 if**

```
if(条件){ 条件成立执行代码; }
```

适用：只处理满足条件场景，不处理不满足情况

2. **双分支 if-else**

```
if(条件){ 成立代码; }
else{ 不成立代码; }
```

适用：只有两种互斥结果（成年/未成年、闰年/平年）

 3. **多分支 if-else if-else**

```
if(条件1){}
else if(条件2){}
else if(条件3){}
else{ 兜底逻辑 }
```

适用：多区间分级（成绩评级、运费、速度分级）

#### 2. 补充特性

1. 简写：分支内仅**一行代码**时可省略大括号

```
if(score<60) Console.WriteLine("不及格");
```

1. 分支嵌套：if内部再写if，用于多层校验（账号密码双重验证）
2. if括号内可直接写布尔变量：`if(true){}`

### 三、switch 等值分支（固定值匹配）

#### 1. 基础标准语法

```
switch(变量)
{
    case 值1:
        代码;
        break; // 必须，跳出switch
    case 值2:
        代码;
        break;
    default: // 匹配不到所有case时执行（等同于else）
        兜底代码;
        break;
}
```

适用场景：变量和固定常量精准匹配（星期、月份、商品编号、血型）

#### 2. switch 穿透（同逻辑复用）

多个case共用一段代码，省略中间`break`

```
case 1:
case 3:
case 5:
    Console.WriteLine("31天");
    break;
```

典型案例：判断每月天数、季节判断

#### 3. C# 新式switch表达式（简化赋值）

```
string 结果 = 变量 switch
{
    匹配条件1 => 返回值1,
    匹配条件2 => 返回值2,
    _ => 默认返回值 // _ 等价default
};
```

优势：直接返回结果赋值，无需书写多行Console

### 四、三元表达式（双分支最简写法）

### 语法

```
条件 ? 成立返回值 : 不成立返回值;
```

特点：整体是**一个值**，可直接赋值变量/打印输出 示例：

```
string res = year%4==0&&year%100!=0||year%400==0 ? "闰年" : "平年";
Console.WriteLine(res);
```

适用：简单二选一判断（奇偶、成年未成年、文件单位换算）

### 五、各类分支对比选择指南

| 结构         | 适用场景                       | 优势                       | 局限                       |
| ------------ | ------------------------------ | -------------------------- | -------------------------- |
| if           | 区间判断、多复杂逻辑、多层嵌套 | 灵活，支持任意组合条件     | 等值匹配时代码冗余         |
| switch       | 固定常量等值匹配               | 代码清晰，穿透简化重复逻辑 | 仅支持等值判断，不能写区间 |
| switch表达式 | 等值匹配并直接取值             | 极简，一行完成判断赋值     | 复杂执行逻辑不适合         |
| 三元运算符   | 简单二选一                     | 代码最短                   | 不支持多行逻辑、多分支     |

### 六、核心实战案例汇总

1. 闰年判断：`year % 4 == 0 && year % 100 != 0 || year % 400 == 0`
2. 成绩分级：多if区间判断 或 switch表达式
3. 月份天数/季节：switch穿透
4. 计算器：switch匹配运算符
5. 账号密码登录：if嵌套双重校验
6. 运费/会员折扣：多分支区间判断

### 七、Day03核心重点

1. 逻辑短路是高频考点：`&&`、`||`会跳过无意义右侧代码，`&`/`|`不会；
2. if擅长**区间、复杂多条件**，switch擅长**固定值等值匹配**；
3. 分支简写规则：单行代码可省略大括号；
4. 三元表达式只做简单二选一，复杂业务优先if；
5. switch穿透用于多个值共用同一套逻辑，大幅精简代码；
6. 新式switch表达式适合需要把判断结果保存到变量的场景。

## Day04 C# 循环结构完整精炼总结

### 一、四大循环基础结构对比

#### 1. while 循环

语法

```
// 先判断条件，成立才执行
int i = 初始值;
while(循环条件)
{
    循环体;
    变量更新;
}
```

执行逻辑：初始化变量 → 判断条件 → 成立执行循环体+自增，不成立直接结束 适用：循环次数不确定、需要手动控制计数，累加、筛选数字、水仙花数等

#### 2. do while 循环

语法

```
int i = 初始值;
do
{
    循环体;
    变量更新;
}while(循环条件);
```

核心特点：**先执行一次循环体，再判断条件**，无论条件真假至少运行1次 适用：需要至少执行一遍的场景（输入校验、菜单重复选择）

#### 3. for 循环（最常用计数循环）

标准语法

```
for(初始化;循环条件;变量自增/自减)
{
    循环体;
}
```

执行流程：初始化仅执行1次 → 判断条件 → 执行循环体 → 更新变量，往复 拓展写法：初始化、变量更新可移到循环外部，分号不可省略 灵活控制变量变化：`i++`递增、`i--`递减、`i+=2`步长为2（直接取偶数） 适用：**已知循环次数**、数组/List下标遍历、九九乘法表、固定次数计算

#### 4. foreach 循环（集合专属遍历）

语法

```
foreach(元素类型 临时变量 in 数组/List/Dictionary)
{
    操作临时变量;
}
```

特点：无需下标，自动取出集合每一个元素，只读无法修改原集合元素 遍历对象：数组、List、Dictionary（item为键值对对象） 适用：只读取集合数据，不需要下标操作的场景

| 循环类型 | 判断时机         | 是否需要下标       | 适用场景                     |
| -------- | ---------------- | ------------------ | ---------------------------- |
| while    | 先判断后执行     | 手动定义下标变量   | 循环次数未知、复杂条件筛选   |
| do while | 先执行再判断     | 手动定义下标变量   | 必须至少执行1次              |
| for      | 先判断后执行     | 自带下标，可控步长 | 固定次数、下标操作、嵌套循环 |
| foreach  | 无条件，自动遍历 | 无下标             | 纯读取数组/List/字典集合     |

### 二、循环控制关键字 break / continue

#### 1. continue

作用：**跳过当前本轮循环**，直接进入下一次条件判断 示例：`i==3`时跳过输出，直接i++继续循环 典型场景：过滤不需要处理的数据、素数判断跳过1和自身

#### 2. break

作用：**直接终止整个循环**，跳出循环块，后续循环不再执行 典型场景：找到目标数据立刻停止、满足临界条件退出循环

### 三、循环嵌套

1. 定义：循环内部再嵌套一层/多层循环（for嵌套最常用）
2. 执行规则：外层循环走1次，内层完整跑完所有循环
3. 经典案例：

- 打印矩形/直角三角形星号图案
- 九九乘法表（外层控制行数，内层控制每行表达式数量）
- 多层数据批量遍历

### 四、高频实战场景

1. 数值运算：1~N累加、累乘、筛选奇数/偶数/公倍数
2. 数字判断：水仙花数、素数、闰年批量筛选
3. 商业计算：薪资逐年涨幅、存款扣费、反弹高度迭代计算
4. 集合遍历：List求和、字符串拼接、字典键值读取
5. 图形打印：星号三角、九九乘法表

### 五、核心要点总结

1. while/for：先判断后执行；do while 保证至少执行一次；
2. for 把计数、条件、更新写在一行，适合固定次数循环；foreach简化集合遍历；
3. continue 只跳过当前轮，break 直接结束全部循环；
4. 循环嵌套内外层变量不能重名，外层循环控制大维度，内层控制细节；
5. 遍历List优先使用`list.Count`获取长度，避免手动数元素；
6. foreach仅读取元素，若需要修改集合数据、操作下标，必须使用for循环。

### 三、List 四种去重实现方案

原始数据允许重复，四种思路从基础到高效：

1. **双层循环删除重复（修改原集合）** 内层从`i+1`开始对比，重复执行`RemoveAt(j)`，删除后`j--`修正索引塌陷。
2. **LastIndexOf 查找尾部重复删除** 循环判断元素首次、最后一次下标不一致，持续删除尾部重复项。
3. **借助字典键唯一特性（推荐）** 遍历List存入字典key，再把Keys转为新List；效率高，代码简洁。
4. **新建空List+Contains判断** 遍历原集合，元素不在新List中才Add，不改动原数组。

### 四、冒泡排序原理与代码

#### 核心逻辑

相邻两个元素两两对比，逆序则交换；外层控制总轮次，内层每轮减少一次对比（末尾已排好序）。

#### 标准升序模板

```
List<int> ints = [5,3,4,6,1,2];
for(int j=0; j<ints.Count-1; j++)
{
    for(int i=0; i<ints.Count-1-j; i++)
    {
        if(ints[i] > ints[i+1])
        {
            int tmp = ints[i];
            ints[i] = ints[i+1];
            ints[i+1] = tmp;
        }
    }
}
```
