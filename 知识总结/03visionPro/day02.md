# day02｜VisionPro 卡尺、几何查找拟合、Fixture定位坐标系、图形标注 精简总结

> 承接day01，重点：卡尺工具、几何查找/拟合、Fixture动态坐标系、图形文本标注格式化。

## 一、上节回顾

1. **CogPMAlignTool(PMA/PatMax模板匹配)**：必须输入灰度图；掩膜Mask屏蔽内部干扰区域；建模器用于自动提取不规则模板轮廓。
2. **CogBlobTool斑点工具**：灰度阈值分割，得到斑点数量、位置、面积；输出图像可交给下一级Blob做二次过滤。

## 二、卡尺工具

- 作用：**查找边缘、边缘对，做长度、宽度尺寸测量**；边缘就是图像上灰度发生剧烈跳变的位置。

- 关键参数

  1. **边缘对宽度**：被测宽度大致预估；

  2. **对比度阈值**：明暗变化程度，数值越大，要求色差越明显；

  3. **过滤一半像素**：边缘过渡占用像素；

  4. **最大结果数**：保留多少条边缘结果；

  5. 浮动显示

     ：依据坐标自动计算实际宽度。

     > 经验：**明→暗方向的边缘更容易被检测到**。

## 三、几何查找与拟合工具

| 工具                       | 功能                               |
| -------------------------- | ---------------------------------- |
| CogFindLineTool            | 查找直线                           |
| CogFindCircleTool          | 找圆（底层是多组卡尺采集点拟合圆） |
| CogFindEllipseTool         | 查找椭圆                           |
| CogFindCornerTool          | 查找角点                           |
| CogFitLineTool             | 对点集合拟合直线                   |
| CogFitCircleTool           | 对点集合拟合圆                     |
| CogFitEllipseTool          | 拟合椭圆                           |
| CogMultiFindLineFinderTool | 批量查找多条直线                   |

> 查找：直接在图像搜特征；拟合：输入一堆点，计算最优几何图形。

## 四、Fixture坐标系工具⭐工业高频

### 问题场景

工件发生旋转、平移，固定ROI查找圆/线就会失效；需要跟随工件姿态变化的局部坐标系。

### 常用工具

1. ```
   CogFixtureTool
   ```

   ：最常用；

   一般配合PatMax(PMA)模板匹配使用

   。

   - 输入PMA输出的2D变换关系，生成新的局部工件坐标系；
   - 输出①变换后的坐标系；②可输出一张逻辑坐标已经转换完成的图像；
   - 后续查找圆、卡尺等工具可以切换到Fixture坐标系，工件旋转平移，工具依然有效。

2. `CogFixtureNPointToNPointTool`、`CogCalibNPointToNPointTool`、`CogCalibCheckerboardTool`：N点标定、棋盘格标定，做真实物理世界单位校正（像素转mm）。

> 典型流程：**PMA模板定位 → CogFixture生成工件局部坐标系 → 在Fixture坐标系下做卡尺、找圆、测量**。

## 五、几何图形创建与文本标注

用于在图像上绘制结果，把坐标、尺寸、OK‑NG直接画在图片上。

1. 绘制基础图形：直线、圆、椭圆。

2. CogCreateGraphicLabel文本标签，支持格式化占位符

   | 占位符 | 含义             |
   | ------ | ---------------- |
   | `{I}`  | 整型数字         |
   | `{D}`  | 浮点数/双精度    |
   | `{B}`  | 布尔值true/false |
   | `{T}`  | 工具结果字符串   |

格式化示例：

- `{D:F2}`：浮点数保留2位小数；
- `{D:P}`：百分比；
- `{D:X}`：十六进制（仅整数）。

> 可以直接把测量得到的圆心、长度、OK/NG标注叠加显示在图像。

## 六、典型作业需求

1. 羊角零件：标记左右两侧是否合格；
2. 轴承：找圆心，标注X、Y，保留两位小数；
3. 三星电池：正面画对勾✓，反面画叉号✗；
4. 针脚检测：统计针脚数量，判断有无掉落弯曲，标记合格/NG；
5. 硬币识别：统计1角、5角、1元硬币正反面数量。

## 七、易错点

1. 卡尺查找优先选择**明到暗的边缘**检出效果更好；
2. Fixture不是直接找特征，是**基于前面定位工具的变换矩阵生成坐标系**，必须前面有PMA等定位工具；
3. 文本标签`{D:F2}`常用做测量值保留小数，方便视觉结果可视化；
4. 查找和拟合区分：Find类直接图像搜特征；Fit是对点集合做数学拟合。

## 📝面试简答

**Q：Fixture工具作用与典型使用流程？😃**

> A：生成跟随工件平移旋转的局部坐标系。典型流程：PatMax(PMA)模板匹配得到工件姿态 → CogFixture接收变换矩阵生成局部坐标系；后续卡尺、找圆工具使用该坐标系，工件移位旋转依旧可以测量。

**Q：查找Find与拟合Fit工具区别？🤔**

> A：Find（找线/找圆）：直接扫描图像像素，查找几何特征；Fit（拟合）：输入一批点集合，数学计算出最优的直线、圆。

**Q：卡尺工具对比度阈值含义？**

> A：代表边缘明暗跳变程度；数值越大，对明暗差异要求越高，弱边缘会被过滤。
