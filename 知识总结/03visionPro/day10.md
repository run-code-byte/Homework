# day10｜VisionPro GigE相机配置、图像格式、触发器、棋盘格标定板标定 精简总结

> 重点：WinForm加载vpp方案代码；GigE工业相机网卡配置、巨型帧；各类图像像素格式；相机四种触发模式；棋盘格标定`CogCalibCheckerboardTool`像素转物理世界毫米坐标。

## 一、WinForm加载VPP作业回顾

核心流程

1. `CogImageFileTool`读取本地图片，转为VisionPro内部图像对象`ICogImage`。
2. `CogSerializer.LoadObjectFromFile()`读取`.vpp`作业文件，强转为`CogJob`，拿到`CogToolGroup`工具组。
3. 找到内部工具实例，给输入图像赋值，调用`Run()`执行工具，读取结果。

```
CogImageFileTool CIFT = new CogImageFileTool();
CIFT.Operator.Open(filePath,CogImageFileModeConstants.Read);
CIFT.Run();
ICogImage inputImg = CIFT.OutputImage;

string vppPath = Path.Combine(Directory.GetCurrentDirectory(),"vpps","xxx.vpp");
CogJob job = CogSerializer.LoadObjectFromFile(vppPath) as CogJob;
CogToolGroup toolGroup = job.VisionTool as CogToolGroup;
//获取工具，赋值输入图像，Run()执行
```

## 二、GigE工业相机网卡配置

1. 电脑网卡IP需要与相机**同一网段**，IP前3段一致，最后一段不同。
2. **巨型帧（MTU）设置9014**：GigE大图像大包传输，防止丢包、花屏、断流。
3. VisionPro自带相机配置工具，用来发现、配置GigE相机。

## 三、相机图像像素格式

| 格式                | 说明                                            | 适用场景                                         |
| ------------------- | ----------------------------------------------- | ------------------------------------------------ |
| Bayer Color拜耳原始 | 原始R/G/B交错点阵，需要软件做拜耳插值生成彩色图 | 精细色彩分析，可后期调白平衡                     |
| Mono8               | 8位灰度，0‑255；带宽最小                        | ⭐最常用，划痕、尺寸、缺陷检测                    |
| Mono10              | 10位灰度，0‑1023；层次更丰富                    | 明暗反差大，高光阴影细节多                       |
| Mono12              | 12位灰度，0‑4095，动态范围最大                  | 微弱亮度差异；带宽压力高，硬件要求高             |
| RGB8                | 硬件输出成品24位彩色图；带宽开销巨大            | 彩色检测，高帧率容易丢包花屏                     |
| YUV422              | 压缩彩色，亮度完整，色彩降采样                  | 需要彩色，但想降低网络带宽，色彩精度要求不能极高 |

> 选型提示：大部分测量、缺陷检测优先选 **Mono8**。

## 四、相机四种触发模式

1. **手动**：点击运行，抓拍一张，调试用。
2. **自由运行FreeRun**：相机不间断持续拍照，类似监控；不受外部传感器控制。
3. **硬件自动**：作业启动后就待命，**外部光电传感器每来一次信号就抓拍一张，循环持续工作**。
4. **硬件半自动**：启动作业，等待一次外部触发信号，拍完本次之后停止，需要重新启动作业。

> 工业产线最常用：硬件自动，工件经过光电传感器，触发相机拍照。

## 五、棋盘格标定板标定 CogCalibCheckerboardTool⭐工业重点

1. 问题：直接测量得到的是**像素值**；实际生产需要毫米等真实物理尺寸。简单比例换算误差大，镜头畸变无法消除。
2. 工具：`CogCalibCheckerboardTool`棋盘格标定板工具。
3. 原理：使用已知真实物理尺寸的陶瓷/金属棋盘格标定板，建立**像素坐标 ↔ 真实世界(mm)坐标**映射关系，同时矫正镜头畸变。
4. 标定完成后，后续测量工具输出直接输出毫米真实物理尺寸，不再是像素。

## 六、易错点

1. GigE相机必须设置巨型帧MTU，否则高分辨率图像极易丢包、花屏。
2. Bayer拜耳原始图像不能直接当彩色图用，必须做拜耳插值。
3. 产线运行优先使用【硬件自动触发】；半自动只响应一次外部触发。
4. 简单按比例换算像素转毫米无法消除镜头畸变，精度差；正式项目使用棋盘格标定板。

## 📝面试简答

**Q：GigE相机为什么要设置巨型帧MTU=9014？😃**

> A：GigE图像数据包很大，调高MTU巨型帧，减少分包，避免网络丢包、图像花屏、断流。

**Q：Mono8、Mono10、Mono12区别？🤔**

> A：Mono8：8位灰度0‑255，带宽小，绝大多数检测首选；位数越高灰度等级越多，动态范围越好，但网络带宽、硬件要求随之变高。

**Q：硬件自动与硬件半自动触发区别？**

> A：硬件自动：作业启动，持续等待外部触发，每来信号拍一张，产线循环工作；硬件半自动：仅响应一次外部触发，拍完即停止，要重新启动作业。

**Q：棋盘格标定作用？**

> A：建立像素坐标和真实物理毫米坐标映射，矫正镜头畸变，让测量结果输出真实物理尺寸，消除镜头带来的测量误差。
