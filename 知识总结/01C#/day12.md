# day12｜回调函数原理、面向对象进阶：构造函数(实例/静态/私有)、继承、多态知识总结

## 1、所学知识清单

### ① 回调函数原理

> 需求：封装通用筛选方法，**筛选条件不写死，由调用方传入**。

1. 普通参数只能传数据；如果业务逻辑（判断条件）要外部传入，就把**函数本身作为参数**，这个入参函数就是**回调函数**。
2. 使用`Func/Action`委托做参数类型；调用通用方法时传入Lambda表达式作为回调。

```
//通用筛选，ConditionFn回调函数：传入元素，返回bool判断条件
List<int> Filter(List<int> arr, Func<int,bool> ConditionFn)
{
    List<int> newList = new List<int>();
    foreach(var item in arr)
    {
        if(ConditionFn(item))
        {
            newList.Add(item);
        }
    }
    return newList;
}
//调用，回调使用lambda
var res = Filter(new List<int>{1,2,30,4,5}, item=>item>10);
```

> 本质：把逻辑“向外移交”，通用框架只负责流程，**具体业务规则交给调用者写回调实现**。LINQ内部Where就是这种回调思想。

### ② 面向对象基础回顾

1. OOP三大特性：**封装、继承、多态**；POP面向过程关注步骤；OOP关注对象，调用对象属性、方法完成业务。

2. 类：模板/图纸；对象：

   ```
   new
   ```

   实例出来的实体。

   - 属性：事物特征，`{get;set;}`，get读，set写；只有get为只读。
   - 方法：事物行为。

3. 访问修饰符

   - `public`：全部可访问
   - `private`：仅本类内部（默认）
   - `protected`：本类 + 子类可访问，外部不可访问
   - `internal`：当前项目内可访问

4. `static`静态：属于**类本身**，类名.静态成员调用；不属于实例对象；静态方法不能直接访问实例成员。

### ③ 三种构造函数

> 构造函数：new实例对象的时候**自动执行**，用来初始化对象成员；**无返回值，名字和类名完全相同**。

1. 实例构造函数
   - 每次`new`对象就执行一次；用来给实例对象属性赋值。
   - 如果不手写任何构造函数，编译器自动生成**无参默认构造函数**；一旦手写自定义构造，默认无参构造消失。
   - 对象初始化器`new Person(){Name="xxx"}`：仅能给`public+set`属性赋值，private/protected/只读属性无效。
2. 静态构造函数 `static 类名(){}`
   - 在**第一个实例创建之前自动执行，整个程序生命周期只执行1次**；
   - 不能手动调用；主要用来初始化静态成员。
3. 私有构造函数 `private 类名(){}`
   - 外部不能`new`创建实例；用于**单例模式**：保证整个程序该类只能创建唯一的一个对象。

```
internal class SingleInstance
{
    static private SingleInstance _instance;
    //私有构造，外部无法new
    private SingleInstance(){}
    public static SingleInstance GetSingleton()
    {
        if(_instance == null)
        {
            _instance = new SingleInstance();
        }
        return _instance;
    }
}
```

> 工业视觉场景：相机、运动控制器可以用单例，防止重复实例化造成设备抢占。

### ④ 继承

1. 语法：

   ```
   class 子类 : 父类
   ```

   - 父类（基类）：存放多个子类**共同的属性、方法**；
   - 子类（派生类）：继承拿到父类成员，再扩展自己独有的属性方法。

2. 继承好处：**代码复用、结构清晰、便于扩展**。

3. 示例：设备基类`Device`，子类`Camera`相机、`MotionController`运动控制、`Plc`PLC；公共连接断开逻辑写父类，子类扩展特有方法。

4. 注意：子类访问权限不能高于父类，父类访问修饰符权限要大于等于子类。

### ⑤ 多态（两种实现方式）

> 多态：同一个父类，不同子类，同一个方法展现不同行为；父类变量可以接收子类对象。

1. 虚方法重写（virtual + override）
   - 父类方法标记`virtual`虚方法；
   - 子类使用`override`重写该方法，改写业务逻辑；
   - 父类类型变量保存子类实例，调用方法时，**执行的是子类重写后的逻辑**。
2. 方法重载（Overload）
   - **同一个类里面**，多个方法**方法名相同，参数列表不同（参数个数/类型不同）**；返回值不参与重载判断。
   - 根据传入实参自动匹配调用对应方法。

```
//虚方法重写示例
class Transport
{
    public virtual void Transportation()
    {
        Console.WriteLine("父类运输");
    }
}
class Ship : Transport
{
    public override void Transportation()
    {
        Console.WriteLine("轮船水上运输");
    }
}
//父类引用指向子类对象
Transport t = new Ship();
t.Transportation(); //执行子类重写方法
```

## 2、易错点

1. 回调函数：`Func<int,bool>`最后一个泛型是返回值类型；回调内部逻辑由调用方提供。
2. 手写任意构造函数，编译器不再提供默认无参构造，再写`new 类名()`编译报错。
3. 静态构造函数：**只会执行一次，不能手动调用**；只处理静态成员。
4. 私有构造函数：只能类内部new；外部直接new会编译报错；单例要判空，只实例化一次。
5. 继承：C#类**只支持单继承**，一个子类只能直接继承一个父类。
6. virtual/override配对：父不加virtual，子类不能写override重写；
7. 方法重载：**只看方法名和参数列表；返回值类型不能作为重载区分依据**。
8. 多态：父类变量存子类对象，只能访问父类定义的成员；子类独有的方法不能直接调用，需要强制转换。
9. 对象初始化器`{}`不能给private、protected、只读（无set）属性赋值。

## 3、拓展（工业视觉上位机）

1. 回调函数：相机拍照完成回调、PLC报文接收回调、通用过滤缺陷集合；框架预留Func/Action回调，业务逻辑由上层传入。
2. 单例模式（私有构造）：相机设备、运动控制类，全局只一个实例，避免多次打开设备造成占用报错。
3. 继承：封装设备基类Device，Camera、Plc、运动控制器继承，复用Connect/Disconnect通用连接断开代码，子类扩展拍照、读写寄存器、轴运动。
4. 多态：设备基类虚方法`Work()`；不同设备子类override重写各自工作逻辑；统一用父类集合管理多种设备。
5. 静态构造函数：初始化全局配置、硬件参数。

## 4、面试重点

1. 什么是回调函数，原理是什么？

   > 将函数作为方法参数传入，称为回调；通用方法固定流程，**把可变业务逻辑交给外部传入的回调函数实现**；LINQ Where底层就是回调。

2. 实例构造函数、静态构造函数、私有构造函数区别和使用场景？

   > 实例构造：每次new对象执行，初始化实例成员； 静态构造：第一个实例创建前执行，**只运行1次**，初始化静态成员，不能手动调用； 私有构造：外部无法new，用于单例模式，保证全局仅有一个对象，适合硬件设备类。

3. 继承的作用？

   > 提取公共代码到父类，实现代码复用，结构清晰，方便扩展；C#类单继承。

4. 多态两种实现方式？virtual和override作用？重载和重写区别？

   > 多态：①虚方法重写 virtual+override；②方法重载。 virtual标记父类虚方法允许子类重写；override子类重写虚方法。 重载：**同一个类中，方法名相同参数不同**；重写：发生在父子类之间，重写virtual虚方法。

5. 单例模式实现思路，私有构造的作用？

   > 静态私有保存唯一实例；私有构造禁止外部new；提供静态方法，判空，内部new返回实例；保证全局只能有一个对象。

> 工业视觉岗位补充：
>
> - 硬件设备类优先考虑单例，防止重复打开相机/PLC；
> - 设备基类用继承，多态实现不同设备统一调度；
> - 回调大量用于相机采集完成事件、报文接收。
