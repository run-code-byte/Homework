# day04｜while / do‑while / for / foreach循环、循环控制关键字、循环嵌套知识总结

## 1、所学知识清单

### ① 上节回顾

- 关系运算符：`> >= < <= == !=`；逻辑运算符`&& || ! & |`，区分短路、非短路运算
- if单/双/多分支、分支嵌套；switch‑case、case穿透、switch表达式；三元运算符

### ② while循环

- 语法：`while(布尔条件){ 循环体; }`
- 执行逻辑：**先判断条件，条件true才执行循环体；条件false一次都不执行**。
- 要点：循环变量要在循环外初始化；循环体内**一定要修改循环变量**，否则死循环。
- 典型案例：累加求和、求水仙花数、倍数筛选。

### ③ do‑while循环

- 语法：`do{循环体;}while(条件);`，末尾**必须带分号**。
- 执行逻辑：**先执行一遍循环体，再做条件判断**；无论条件真假，循环体至少执行1次。
- 适合场景：密码校验、至少要执行一次的业务。

### ④ for循环

- 语法：`for(初始化;条件判断;迭代更新){循环体;}`

1. 第一步：初始化（仅执行1次）
2. 第二步：判断条件；true执行循环体，false结束循环
3. 第三步：执行迭代更新，回到第二步判断

- 灵活写法：初始化写外部、迭代写循环体内；支持递增、递减、步长自定义（`i+=2`）。
- 适合**已知循环次数**；常用来按下标遍历数组、List集合（使用`.Count`作为边界）。

### ⑤ 循环控制关键字

1. `continue`：**跳过本次循环剩余代码，直接进入下一轮循环判断**，不会结束整个循环。

2. ```
   break
   ```

   ：

   立刻终止整个循环

   ，跳出循环块，执行循环后面的代码。

   > 注意：`break`只跳出**当前一层循环**，嵌套循环不会直接跳出全部外层。

### ⑥ foreach循环

- 语法：`foreach(元素类型 变量 in 集合){}`
- 专门遍历**数组、List、Dictionary**集合；**直接拿到元素，没有下标**。
- 特点：不能获取索引；遍历集合时，**不要直接Add/Remove修改原集合，会报错**。

### ⑦ 循环嵌套

- 循环内部再写循环；**外层循环跑1次，内层完整跑完一轮**。
- 案例：星号图形、九九乘法表。

### ⑧ 常见算法练习

累加、累乘、水仙花数、阶乘、复利计算；作业包含：闰年筛选、分数级数求和、弹球高度、猴子吃桃等逻辑题。

## 2、易错点

1. while循环忘记更新循环变量，造成**死循环**。
2. do‑while末尾容易漏写分号 `;`，编译报错。
3. for循环三个表达式用分号`;`分隔，**不是逗号**。
4. `continue`在while中使用，如果continue前没有做变量自增，会直接死循环；for循环会自动执行第三部分迭代更新。
5. `break`只退出当前一层循环，嵌套循环不能直接跳出所有层。
6. foreach遍历集合时，循环体内不要对集合做Add、Remove，抛出集合修改异常。
7. for遍历List边界写死数字，集合元素数量变化时代码出错；要用`list.Count`，不要写固定数字。
8. 整数除法，`1/2`结果为0，做级数求和要转为`1.0 / i`得到小数。
9. 循环嵌套内外层变量不要重名；打印图形区分`Console.Write()`不换行与`Console.WriteLine()`换行。

## 3、拓展

1. 四种循环选型

   | 循环     | 特点                     | 适用场景                         |
   | -------- | ------------------------ | -------------------------------- |
   | while    | 先判断后执行，次数未知   | 不确定循环多少次，满足条件才停止 |
   | do‑while | 至少执行1次              | 输入校验、至少执行一次的逻辑     |
   | for      | 初始化、条件、迭代放一起 | **明确循环次数、需要下标访问**   |
   | foreach  | 只读遍历集合，无下标     | 只读取集合全部元素，不需要索引   |

2. 工业视觉上位机场景：

   - `for`：遍历检测缺陷List集合，按索引获取缺陷坐标、面积；遍历相机点位。
   - `while`：轮询等待PLC信号、等待拍照完成；注意上位机界面不能直接用死循环，会卡死UI。
   - `foreach`：遍历参数字典、遍历检测结果。

3. 死循环写法 `while(true)`、`for(;;)`，必须搭配`break`设置退出条件。

4. 嵌套循环跳出全部：可以使用布尔标记变量，不推荐goto。

## 4、面试重点

1. `while`和`do‑while`的区别？

   > while先判断后执行，条件不成立一次不执行；do‑while先执行一次再判断，**至少执行1次**；do‑while结尾有分号。

2. `break` 和 `continue` 的区别？

   > `break`终止**整个循环**，跳出循环；`continue`仅**跳过本次循环**，继续下一轮。break只跳出当前一层嵌套循环。

3. for循环执行顺序？

   > ①初始化（仅1次）→②条件判断→true执行循环体→③迭代更新，回到条件判断；条件false结束。

4. for与foreach区别，foreach有什么限制？

   > for可以拿到下标，可以修改集合元素；foreach只读遍历集合，拿不到索引；遍历过程不能增删集合元素，会报异常。

5. 什么情况会产生死循环？

   > while循环忘记更新循环变量；continue跳过了变量自增；条件永远为true没有break退出。

6. 循环嵌套执行逻辑？

   > 外层循环每执行1次，内层循环完整全部执行一遍。

> 工业视觉岗位补充：上位机遍历缺陷列表、解析PLC多条报文、处理相机多点位数据大量使用for/foreach；轮询设备状态会用到while，注意死循环阻塞界面问题。
