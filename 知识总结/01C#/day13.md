# day13｜抽象类abstract、静态类static、密封类sealed、接口interface、this关键字、属性访问器知识总结

## 1、所学知识清单

### ① 上节快速回顾

- 回调函数：把`Func/Action`委托作为参数，框架固定流程，业务逻辑外部传入；LINQ底层就是回调。
- 面向对象基础：类与对象、访问修饰符；实例/静态/私有构造函数；继承；多态（virtual‑override重写、方法重载）。

### ② 抽象类 abstract

1. 关键字`abstract`修饰类；**抽象类不能new实例化**，存在的意义就是**专门用来被继承**。
2. 抽象方法：`public abstract void Func();`，**没有方法体，只有签名**，强制子类必须实现。
3. 抽象类里面既可以有抽象方法，也可以包含普通属性、普通方法（公共逻辑直接复用）。
4. 继承规则：
   - 普通子类继承抽象类：**必须override实现全部抽象方法，否则编译报错**。
   - 如果子类同样是`abstract`抽象类，可以不实现父类抽象方法。
5. 三大作用
   1. 提取公共属性、普通方法，实现代码复用；
   2. 使用抽象方法**定规范、定契约**，强制子类必须实现某些功能，团队协作避免遗漏；
   3. 支持多态：用抽象父类类型接收各个子类对象，编写统一处理逻辑。

> 示例场景：设备父类，定义抽象`Connect()`、`Disconnect()`，相机、PLC、运动控制器子类各自实现连接断开逻辑。

### ③ 静态类 static class

1. 使用`static`修饰类；**不能new实例、不能被继承**。

2. 静态类内部**全部成员强制为static静态**，不能写实例成员。

3. 用途：工具类，存放一堆通用工具算法方法，直接

   ```
   类名.方法()
   ```

   调用。

   > 工业视觉示例：`VisionTool`，封装像素换算、距离计算、阈值判断、角度归一化等工具函数。

### ④ 密封类 sealed

1. `sealed class`密封类：**禁止被其他类继承**。
2. 密封方法：`public sealed override void Method()`；必须配合`override`使用；**阻止子类继续重写该虚方法**。

### ⑤ 接口 interface

1. 接口代表**能力/行为规范**，只定义契约，不写业务实现；理解成一份说明书。

2. 语法：`interface Ixxx{}`；接口成员**默认全部public，不能写访问修饰符**；只写属性签名、方法签名，没有实现体。

3. 类实现接口：`class 类名 : 接口名`，类**必须实现接口里面全部成员**。

4. 重要区别：

   - 类：C#只支持**单继承**，一个类只能继承一个父类；
   - 接口：一个类**可以同时实现多个接口**，用逗号隔开。

5. 接口用来实现多态：接口类型变量可以接收任意实现该接口的类的对象。

   > 示例：`IImageGrabber`图像采集接口，海康相机、Basler相机分别实现接口；上层代码只依赖接口，不用关心具体相机型号。

### ⑥ this关键字（只能写在类的非静态成员中，静态方法不能用this）

1. **区分成员与局部变量**：当参数名和类属性重名，`this.属性名`代表当前实例对象的属性。

```
public Person(string Name)
{
    this.Name = Name;
}
```

1. **把当前实例作为参数传递给别的方法**：`CardHelper.PrintInfo(this);`
2. **构造函数串联调用**：`public A(string a):this(a,"默认值")`，调用本类另外一个实例构造函数，减少重复代码。
3. **索引器**：`public 返回值 this[索引类型 index]{get;set;}`，让对象可以像数组/字典一样使用`obj[0]`下标访问；`set`块中`value`代表传入的赋值。

### ⑦ 属性访问器 get / set

1. 简单自动属性：`public string Name {get;set;}`编译器自动生成后台私有字段。
2. 完整手写属性，搭配私有后台字段，在`get`、`set`内部写业务校验、数据加工逻辑。

```
private string _cardNo;
public string CardNo
{
    get => _cardNo;
    set
    {
        //赋值校验，非法直接抛异常
        if(string.IsNullOrEmpty(value) || value.Length<10)
            throw new Exception("卡号格式非法");
        _cardNo = value;
    }
}
```

1. 权限控制：

   ```
   public decimal Balance {get; private set;}
   ```

   ，外部只能读，仅类内部可以赋值。

   - get：读取属性时执行；可以对返回数据做加工；
   - set：给属性赋值时执行；`value`关键字代表外部传入要赋的值。

## 2、易错点

1. 抽象类**不能new**；普通子类继承抽象类必须实现所有abstract抽象方法，否则编译报错。
2. 静态类不能实例、不能继承，全部成员必须static。
3. sealed密封方法**只能写在override重写的方法上面，不能直接修饰virtual**。
4. 接口内部成员**默认public，不能写private/protected修饰符**。
5. 类单继承，接口可以多实现，不要混淆继承和实现接口语法。
6. `this`**不能出现在static静态方法里面**。
7. 构造函数串联`this(参数)`只能写在构造函数的冒号后面，普通方法不能使用。
8. 属性set里面，`value`是系统关键字，代表外部传入赋值，不能自己定义。
9. 自动属性不能直接写校验逻辑；要校验必须手写私有后台字段，完整实现get/set。

## 3、拓展（工业视觉上位机）

1. **抽象类**：提取硬件设备公共骨架；抽象方法强制不同设备实现连接、采集；统一抽象父类做设备集合多态管理。
2. **静态类**：大量写工具类，坐标换算、灰度判断、数学计算，全局直接调用，不用new对象。
3. **密封类sealed**：稳定的工具实体类，不希望后续项目被继承篡改，可以加sealed。
4. **接口**：非常常用，定义硬件能力接口`IImageGrabber`、`ITrigger`；不同品牌相机实现同一套接口；上层业务只依赖接口，切换相机不需要修改业务代码（解耦）。
5. **this索引器**：缺陷集合、点位集合封装类，可以用索引器像数组一样访问内部元素。
6. **属性get/set校验**：设备参数、缺陷面积、坐标赋值的时候做合法性校验，拦截非法数值，提前暴露错误。

## 4、面试重点

1. 抽象类abstract特点，什么时候用抽象类？抽象方法作用？

   > 抽象类不能实例化，用于被继承；可以有普通成员+抽象方法；抽象方法没有方法体，强制子类实现；用来提取公共代码、定契约规范，支撑多态。

2. 静态类static class特点，使用场景？

   > 不能实例、不能被继承；全部成员static；用来封装工具方法。

3. sealed密封类与密封方法作用？密封方法注意点？

   > sealed类禁止继承；sealed方法写在override上，阻止子类继续重写；不能直接修饰virtual。

4. 接口interface作用；接口和抽象类区别？

   > 接口定义能力规范；类可以实现多个接口； 区别：抽象类可以有字段、普通实现代码；接口只定义契约；类只能继承一个类，但可以实现多个接口；抽象类可以有构造函数，接口没有构造函数。

5. this关键字有哪4个用途？静态方法能否使用this？

   > ①区分实例属性与局部变量；②传递当前实例对象；③构造函数互相调用；④实现索引器；静态方法不能使用this。

6. 属性访问器get/set；value关键字作用；为什么手写后台字段？

   > get读取，set赋值；set中的value代表外部传入的值；手写后台字段，在get/set里面做赋值校验、数据加工，控制读写权限。

> 工业视觉补充：
>
> - 设备模块大量使用抽象类、接口，实现不同相机、PLC统一调度，方便替换硬件；
> - 算法换算全部放到static静态工具类；
> - 参数属性set访问器做参数合法性校验，防止非法参数传入造成硬件异常。
