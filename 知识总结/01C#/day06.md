### ② string字符串基础

1. **字符串只读**：可以下标读取单个字符，**不能通过下标修改字符**；字符串修改会产生新字符串，原字符串不变。
2. `char`字符类型：单引号`'A'`，代表单个字符，可以和ASCII整型互相转换。
3. null可空
   - `null`：变量不指向任何内存数据；普通值类型`int`不能直接赋值null；
   - 可空类型语法：`int? a = null;`；string引用类型本身就可以赋值`string s=null;`
   - 注意区分：`null`、空字符串`""`、全空格`"   "`三者不一样。

### ③ string 常用属性与方法

| 方法/属性                               | 作用                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| `.Length`                               | 获取字符串字符总长度                                         |
| `string.IsNullOrEmpty(str)`             | 判断是否为`null`或者空字符串`""`                             |
| `string.IsNullOrWhiteSpace(str)`        | 判断是否为`null`、空、全空白空格                             |
| `Substring(start)`                      | 从start下标截取到末尾                                        |
| `Substring(start,count)`                | 从start下标，截取count个字符                                 |
| `Contains("子串")`                      | 是否包含子串，返回bool                                       |
| `StartsWith()`                          | 判断是否以指定内容开头                                       |
| `EndsWith()`                            | 判断是否以指定内容结尾                                       |
| `IndexOf()`                             | 子串第一次出现下标，找不到返回`‑1`，可指定起始查找位置       |
| `LastIndexOf()`                         | 子串最后一次出现下标，找不到返回`‑1`                         |
| `ToUpper()`                             | 全部转大写；返回新字符串，原串不变                           |
| `ToLower()`                             | 全部转小写；返回新字符串，原串不变                           |
| `Trim()` / `TrimStart()` / `TrimEnd()`  | 去除两端/开头/结尾空格，也可指定去除字符                     |
| `Replace(旧,新)`                        | 全部替换匹配子串，返回新字符串                               |
| `Split()`                               | 按分隔符分割，返回字符串数组；`StringSplitOptions.RemoveEmptyEntries`移除分割产生的空项；支持多分隔符 |
| `string.Concat()`                       | 拼接多个字符串/字符串数组                                    |
| `string.Join(连接符,集合)`              | 把数组/List用连接符拼接成一个完整字符串（高频）              |
| `PadLeft(总长度,填充字符)`              | 左边补字符达到指定总长度                                     |
| `PadRight(总长度,填充字符)`             | 右边补字符达到指定总长度                                     |
| `Remove(start)` / `Remove(start,count)` | 删除一段字符，返回新字符串                                   |

> 案例：手写字符串去重、敏感词替换、单词反转大小写转换。

### ④ 正则表达式 `System.Text.RegularExpressions`

> 需要引入命名空间；字符串前缀`@`原义字符串，避免转义。

1. 三大核心静态方法

   - `Regex.IsMatch(字符串,正则)`：**判断是否匹配，返回bool，用于校验格式**
   - `Regex.Match(字符串,正则)`：**提取第一个匹配结果**，返回Match对象，`.Value`拿到匹配内容，`.Groups`拿到分组内容
   - `Regex.Matches(字符串,正则)`：**提取全部匹配项**，返回`MatchCollection`集合
   - `Regex.Replace(字符串,正则,替换内容)`：按规则替换内容

2. 元字符（匹配单个字符）

   | 符号              | 含义                                                         |
   | ----------------- | ------------------------------------------------------------ |
   | `.`               | 任意一个字符                                                 |
   | `\d`              | 数字；`\D`非数字                                             |
   | `\w`              | 数字字母下划线；`\W`非数字字母下划线                         |
   | `\s`              | 空白空格；`\S`非空白                                         |
   | `[abc]`           | a/b/c任意一个；`[a‑z]`小写字母；`[0‑9]`数字；`[A‑Z]`大写字母 |
   | `[^abc]`          | 除abc之外任意字符                                            |
   | `[\u4e00‑\u9fa5]` | 匹配一个汉字                                                 |

3. 量词（修饰前面字符出现次数）

   | 符号    | 含义                |
   | ------- | ------------------- |
   | `*`     | 0次或多次（任意个） |
   | `+`     | 至少1次             |
   | `?`     | 0次或者1次          |
   | `{m}`   | 恰好m次             |
   | `{m,}`  | 最少m次             |
   | `{m,n}` | m~n次               |

4. 锚点与其他符号

- `^`：正则开头，匹配字符串**开头**；`$`：正则末尾，匹配字符串**结尾**；完整校验格式必须同时`^...$`
- `|`：或者
- `\`：转义，匹配 `. * + ?`这类特殊符号需要转义 `\.`
- `()`：分组捕获，`Groups[0]`完整匹配结果，`Groups[1]`第一个小括号分组；`(?: )`非捕获分组，只匹配，不生成分组。

> 实战案例：手机号、QQ、QQ邮箱、提取文本数字、身份证解析提取年月日。

## 2、易错点

1. string是**只读**，所有字符串方法不会修改原字符串，**必须接收返回值**。

```
str.Replace("a","b"); //错误！str本身不变
str = str.Replace("a","b"); //正确，接收返回新字符串
```

1. 区分 `null`、`""`、`"   "`；`null`字符串调用任何字符串方法直接抛空引用异常。优先用`IsNullOrWhiteSpace`做输入校验。
2. `Substring(start,count)`第二个参数是**字符个数**，不是结束下标，容易和其他语言混淆。
3. `Split`分割连续分隔符会产生空字符串，需要加上`StringSplitOptions.RemoveEmptyEntries`移除空项。
4. 正则不写`^ $`只会“包含匹配”，不是完整字符串校验；校验手机号、身份证必须首尾锚定。
5. 正则特殊符号 `. + * ? \` 需要转义，C#中使用`@""`原义字符串，否则要双反斜杠`\\.`。
6. `Match`只拿第一个匹配；要拿全部必须用`Matches`。
7. 分组下标：`Groups[0]`永远是整体匹配结果，**分组从下标1开始**。

1. 工业上位机场景

## 4、面试重点

1. C#字符串的特点？为什么修改字符串不会改变原字符串？

   > string是只读（不可变），所有操作返回新字符串对象；原字符串在内存不会修改。

2. `IsNullOrEmpty` 和 `IsNullOrWhiteSpace`区别？

   > IsNullOrEmpty判断null或者空字符串`""`；IsNullOrWhiteSpace额外把全空格空白也判定为true。

3. `Substring`两个参数分别代表什么？

   > 第一个：起始下标；第二个：截取**字符个数**，不是结束索引。

4. `Split`分割什么时候出现空字符串？如何处理？

   > 连续分隔符会产生空字符串；使用`StringSplitOptions.RemoveEmptyEntries`移除空项。

5. `Regex.Match`与`Regex.Matches`区别？

   > Match获取第一个匹配结果；Matches获取全部匹配结果集合。

6. 正则中`^`与`$`作用；为什么校验手机号要加`^ $`？

   > ^匹配字符串开头，$匹配结尾；不加只是只要文本里面包含就匹配；加上才是**整个字符串完全符合规则校验**。

7. 正则分组`()`；`Groups[0]`、`Groups[1]`含义；`(?:)`非捕获分组作用？

   > Groups[0]完整匹配内容；Groups[1]第一个括号捕获分组；`(?:)`只做匹配，不生成捕获分组，不占用Groups下标。

> 工业视觉补充：上位机接收PLC、MES报文，大量使用字符串截取分割、正则提取产品SN码、缺陷编号、报文数字。
