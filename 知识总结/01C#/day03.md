# day03｜关系&逻辑运算符、if分支、switch分支、三元表达式知识总结

## 1、所学知识清单

### ① 上节内容回顾

- `Math`数学工具类：`Math.PI`、`Abs`、`Pow`、`Sqrt`、`Round`、`Floor`、`Ceiling`、`Max`、`Min`、三角函数`Sin/Cos`
- `var`编译类型推导；`dynamic`运行时动态类型；匿名类型`new { }`只读对象
- 集合：Dictionary字典、数组、List集合基础API

### ② 运算符

1. **关系（比较）运算符**：`> >= < <= == !=`，运算结果一定是`bool`布尔值。

2. 逻辑运算符

   | 符号 | 作用           | 特点                                 |
   | ---- | -------------- | ------------------------------------ |
   | `&&` | 逻辑与（并且） | **短路**：左边 false，右边代码不执行 |
   | `||` | 逻辑或（或者） | **短路**：左边 true，右边代码不执行  |
   | `!`  | 逻辑非（取反） | true 变 false，false 变 true         |
   | `&`  | 非短路与       | 两边表达式全部执行                   |
   | `|`  | 非短路或       | 两边表达式全部执行                   |

> 短路运算作用：可以规避异常，例如判断除数不为0再做除法。

### ③ if条件分支

1. **单分支** `if(条件){ }`：条件为true才执行大括号代码。

2. **双分支** `if(){ } else { }`：true执行if块，false执行else块。

3. **多分支** `if(){} else if(){} … else{}`：从上向下依次判断，匹配到一个分支后其余不再执行；`else`可选。

4. **省略大括号**：分支内部**仅有一行代码**，可以去掉大括号，仅紧跟的第一行属于分支。

5. 分支嵌套

   if内部继续写if‑else，实现多层判断。

   > 经典案例：闰年判断、成绩等级划分。

### ④ switch多路分支

1. 普通`switch‑case`：匹配变量等于case常量；每个case末尾一般写`break`跳出switch。
2. **case穿透**：多个case不写break，共用同一套执行逻辑，适合多值同一处理（月份判断季节、月份天数）。
3. `default`等价于if的else，所有case都不匹配时执行。
4. C#新版**switch表达式**：`变量 switch {条件=>返回值, _=>默认值}`，直接返回结果，适合赋值。

### ⑤ 三元表达式

- 语法：`条件 ? 成立返回值 : 不成立返回值;`

- 等价简化双if‑else；

  整体是一个值，可以赋值、直接打印输出

  适合简单二选一逻辑。

  > 案例：奇偶判断、闰年平年、单位换算。

## 2、易错点

1. 多分支`else if`顺序很关键，条件范围大的写后面，否则逻辑出错。

```
//错误示范，小于100会直接进入第一个分支
if(score <100){}
else if(score<60){}
```

1. if省略大括号的时候，**只有紧跟的第一行归if管**，后续代码不受条件控制，容易踩坑。

```
if(false)
    Console.WriteLine("A");
Console.WriteLine("B"); // 无论条件，B一定会执行！
```

1. switch case后面是**常量值**，不能直接写范围表达式（旧版C#）；范围判断优先用if或者新版switch表达式。
2. switch普通case忘记写`break`会发生穿透，代码继续向下执行，不是报错，是逻辑bug。
3. `&&`和`&`不要搞混；`&`不会短路，可能出现除零等异常。
4. 三元运算符**只能处理二选一**，不能写复杂业务逻辑；不能写多条语句。
5. 闰年条件：`year%4==0 && year%100!=0 || year%400==0`，运算符优先级，不要乱加括号导致逻辑错误。
6. `==`用于相等判断，不要写成赋值`=`。

## 3、拓展

1. 工业上位机开发中大量使用分支：判断PLC反馈信号OK/NG、判断相机拍照是否成功、判断检测缺陷数量、判断设备状态。
2. 短路`&&`常用写法安全防护：`if(n2!=0 && n1/n2>10)`，先判断除数不为0，再做除法运算，防止除零异常。
3. switch表达式适合做映射表，比如血型映射描述、错误码映射提示文本，代码更简洁。
4. 三元表达式可以嵌套，但嵌套层级太深可读性变差，不建议多层嵌套。
5. 布尔变量可以直接写`if(isOk){}`，不需要写`if(isOk == true){}`。

## 4、面试重点

1. 简述`&&`与`&`、`||`与`|`的区别，什么是短路运算？短路有什么好处？

   > `&&`/`||`短路，条件满足就不再执行后面表达式，可以避免异常；`&`/`|`两边全部执行。

2. if多分支执行逻辑；省略大括号有什么坑？

   > 从上到下匹配，命中一个即结束；省略大括号，仅紧跟一行属于分支，其余代码不受条件控制。

3. switch case穿透是什么，什么场景使用？

   > case不写break，执行完当前case继续向下执行后续case；适合多个不同值执行相同逻辑，如月份判断季节。

4. 三元运算符特点，适合什么场景？

   > 双分支简写；表达式整体返回一个结果；适合简单二选一，不适合复杂逻辑。

5. 写出闰年判断条件。

   > `year % 4 == 0 && year % 100 != 0 || year % 400 == 0`

6. 什么时候用if，什么时候用switch？

   > 做范围判断、复杂逻辑判断用if；变量匹配多个固定常量值优先switch。

> 工业视觉岗位补充：上位机接收PLC信号、缺陷结果OK/NG判断、设备状态判断大量使用if‑else；错误码、指令码匹配常用switch。
