Q14：视觉定位的原理有了解吗？简述一下是怎么实现的，如果进行角度旋转怎么抓的准？ A：

   - 使用支持旋转的模板匹配（PatMax），直接输出精确旋转角度。
   - 做旋转标定，校准旋转中心，补偿旋转带来的坐标偏移。
   - 用圆孔、直线等几何特征做二次精定位，修正角度偏差。

Q2：2D相机就能检测物件尺寸了，为什么还要3D激光扫描仪 A：

1. 维度差异：2D只能检测平面投影尺寸，无法获取高度、深度、台阶、翘曲等Z轴方向信息；3D可以直接获取高度差、平面度、轮廓度、体积等立体形貌参数。
2. 缺陷类型：2D无法检测凹坑深度、凸起高度、焊缝余高、胶路厚度、工件翘曲等立体缺陷；3D可以直接量化形貌类缺陷的数值。
3. 抗干扰性：2D尺寸检测受光照、工件颜色、表面反光影响大；3D激光基于轮廓成像，不受灰度、色差、表面反光影响，稳定性更高。
4. 复杂场景：工件有高低起伏、曲面、台阶时，2D会出现透视畸变、尺寸失真；3D可以直接还原真实三维尺寸，不受工件高低位置影响。

Q3：深度学习用的多吗 A：

1. 不算主力，**占比约20%**，作为传统视觉的补充方案使用。
2. 主要用于传统算法难以稳定检出的场景：比如不规则划痕、复杂背景下的污渍、异形缺料、纹理表面缺陷。
3. 用过YOLO做缺陷目标检测、U-Net做缺陷分割，能够独立完成数据标注、模型训练、参数调优，以及C#端工程化部署集成。
4. 常规固定特征、规则明确的缺陷，优先用传统视觉算法，速度快、成本低、可解释性强。

Q4：九点标定做过吗？ A：

Q6：九点标定公式怎么写的 A：

1. 本质是

   二维仿射变换

   ，包含平移、旋转、缩放、剪切，公式为：

   - X = a·x + b·y + c
   - Y = d·x + e·y + f  其中(x,y)为像素坐标，(X,Y)为机械世界坐标，a~f为仿射变换6个参数。

2. 矩阵形式：  `[X; Y] = [[a, b], [d, e]] · [x; y] + [c; f]`

3. 9组坐标通过最小二乘法拟合求解最优矩阵，比3点法更鲁棒，可抵消部分点位采集误差与镜头畸变。

Q14：能描述一下MVVM架构吗？具体怎么实现的 A：

   Model-View-ViewModel

   三层架构，核心是解耦界面与业务逻辑，便于维护和单元测试。

   - Model：数据模型层，包含业务数据、业务逻辑、数据访问，不依赖界面。
   - ViewModel：中间层，连接View与Model，处理业务逻辑，封装属性与命令。

   - 业务逻辑在Model中实现，ViewModel调用Model方法，将结果通过属性暴露给View。
   - WPF中通过Binding、Command、数据模板完成完整绑定，实现界面与业务完全解耦。

Q2：3D激光线扫轮廓仪的原理知道吗？ A：

1. 核心原理是**激光三角测量法**。
2. 线激光发射器垂直或倾斜向被测物体表面投射一条连续的激光线，激光在工件表面发生漫反射。
3. 另一侧的CMOS/CCD图像传感器以固定夹角接收反射的激光条纹，工件表面的高度变化会让激光条纹在传感器上产生横向偏移。
4. 根据三角几何关系，通过计算条纹的偏移量，就能换算出对应位置的高度值，得到一条线上的轮廓高度数据。
5. 配合工件与相机的相对匀速运动，逐行采集轮廓数据，最终拼接成完整的三维点云或高度图。

Q3：你项目中用到的3D激光轮廓仪是线扫还是点激光？是用来干什么的？ A：

1. 项目中用的是**线激光轮廓仪（线扫）**，不是单点激光位移传感器。
2. 主要用途有三类：
   - 尺寸测量：台阶高度、胶路厚度、焊锡余高、材料厚度、槽深槽宽等Z轴方向尺寸。
   - 形貌检测：工件翘曲度、平面度、凹坑深度、凸起高度等立体形貌缺陷。
   - 轮廓检测：焊缝成型轮廓、工件截面形状、边缘毛刺、崩边等轮廓类缺陷检测。

Q7：3D激光线扫过程中产生的阴影如何消除？ A：

1. 硬件光路优化：
   - 调整激光入射角度和接收角度，避开工件陡峭结构、立壁的遮挡，从根源减少阴影产生。
   - 采用双角度或多角度激光扫描，从不同方向投射激光，融合多组点云数据，互相补充阴影缺失区域。
2. 成像参数优化：
   - 合理调整激光功率、曝光时间、增益参数，增强弱反射区域的信号强度，弱化阴影边界的噪声。
   - 针对高反光、透明工件，增加漫射处理或配套偏振器件，减少镜面反射导致的假阴影与信号丢失。
3. 软件后处理：
   - 点云去噪过滤无效阴影噪点，通过邻域插值、曲面拟合补全小范围阴影缺失区域。
   - 结合工件CAD数模做约束拟合，对结构已知的阴影区域进行模型补全，还原真实轮廓。
   - 设置高度、梯度阈值，区分真实阴影与实际缺陷，避免阴影被误判为缺陷。
