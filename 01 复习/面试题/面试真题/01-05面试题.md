Q1：如果让你去设计一个多线程管理，你是怎么去设计？

 A：区分任务类型：CPU算法任务交给线程池；硬件采集这类长时间阻塞任务单独开专用线程。搭建任务队列，限制并发数量；使用CancellationToken实现安全取消；共享资源采用Concurrent集合、Interlocked、lock保证线程安全；任务内部增加异常捕获；监控队列长度、任务耗时；及时释放图像这类非托管资源；队列过载时做限流处理。

Q2：除了核心线程、最大线程、任务队列，还有什么其他要考虑的因素吗？ 

A：任务优先级、任务超时、异常重试、取消令牌、线程安全、非托管资源释放、队列过载策略、运行监控。

Q3：你们项目中用海康相机做什么？是做OCR识别还是做什么？

A：海康GigE工业相机用来采集工件图像，传给VisionPro完成划痕、缺料、孔洞、尺寸这类缺陷检测，不是OCR识别。采用硬件触发拍照，配合PLC保证拍照时机。

Q4：怎么提升MySQL的查询效率？

 A：提升 MySQL 查询效率主要从 3 个层面入手：

1. 索引层面：给查询 / 排序 / 关联字段建合适索引（遵循最左匹配），避免索引失效，用 EXPLAIN 分析索引使用情况；
2. SQL 层面：精简查询字段、减少子查询、优化分页语句，小表驱动大表；
3. 架构 / 配置层面：调大 InnoDB 缓存池、用 SSD 硬盘，大数据量时分库分表 / 读写分离，热点数据加 Redis 缓存。 另外，定期维护索引、优化存储引擎也能进一步提升效率。

Q5：MySQL本地磁盘存储的两种方式是哪两种？MySQL的存储引擎有哪两种？ 

A：MySQL 本地磁盘存储最核心的两种方式对应两大存储引擎：

1. InnoDB：事务型引擎，数据和索引聚簇存储，支持 ACID 和行锁，是默认引擎；
2. MyISAM：非事务型引擎，数据和索引分离存储，仅支持表锁，查询效率高但不保证事务一致性。 如果是按存储格式分，也可以分为行存储和列存储两种方式。
