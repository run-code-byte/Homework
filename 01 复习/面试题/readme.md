2. **臻彦盛基**：重庆小型自动化，一人多岗，上位机+PLC非标；
3. **晴图微视**：视觉专精小公司，**和你的VisionPro、C#上位机技术栈最匹配**；
4. **荣旗科技**：上市设备厂，消费电子AI视觉量产设备，出差较多；
5. **赛那德**：机器人3D视觉，偏向物流具身智能，和传统2D缺陷检测不一样。
6. **创凯智能**：音视频可视化厂商，上位机开发可用，但工业2D缺陷视觉项目很少，VisionPro基本不用；
7. **上海鉴泉自动化**：工业视觉集成商，2D+3D视觉项目丰富，VisionPro、上位机、机器人视觉都能接触；
8. **浙江匠选科技**：自研光学分选设备厂，大量五金/3C零件缺陷检测，完整覆盖硬件选型到量产；
9. **北京华智微视**：印刷卷料专项视觉，赛道单一，做在线飞拍视觉与视觉MES开发；
10. **成都利视通光电**：康耐视核心合作伙伴，主打VisionPro二次开发，完全匹配VisionPro+C#上位机技术栈。
11. **匹配度最高：汇锦美：**上位机+视觉集成+MES数据库，和你C# Winform+VisionPro技术栈高度契合，做产线非标项目，能积累完整项目落地经验。
12. **次选：易唯思：**国产视觉设备厂，2D/3D+AOI，上位机和视觉开发都有，可接触硬件评估到量产全流程。
13. **威华智能**：主打光伏锂电AI视觉，偏向算法，Halcon深度学习为主，上位机岗位相对少。
14. **微纳智感**：高端微观精密光学检测，赛道前沿，但和常规产线视觉上位机方向差异大。
15. **康耐视**：行业头部，VisionPro原厂，简历镀金价值大，但门槛高，岗位多为应用工程师，纯开发岗竞争激烈。
16. **匹配度最高：立讯机器人**，大厂平台，VisionPro+C#上位机、3C视觉检测项目，完全贴合你的技术栈，履历增值效果最好。
17. **次选：苏州鸿麦微智能**，小集成商，可以独立负责整套视觉项目，VisionPro项目多，适合积累全流程项目经验。
18. **浙江豪斯特**：汽车零部件厂，项目稳定，行业标准高，但场景局限于汽车零部件，且有出差。
19. **上海深视科技**：AI视觉赛道，适合想拓展深度学习能力，但传统VisionPro上位机岗位偏少。
20. **广东伟创五洋智能**：业务偏向物流仓储，缺陷视觉项目少，匹配度最低。
