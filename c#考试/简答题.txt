1、
数组：适合数据个数已知、长度固定，不需要频繁增删，追求较高执行效率的场景。
List<T>：适合存储一组有序同类型数据，元素数量不确定，频繁增删、筛选遍历元素的场景。
Dictionary<TKey,TValue>：适合键值映射，需要根据键快速查找对应值，键具有唯一性的场景。

2、
封装：将数据与操作数据的方法封装到类中，隐藏内部细节，对外提供访问接口，保护数据，提高代码安全性。
继承：派生类可以获取基类的成员，实现代码复用，并且可以扩展派生类自身的功能。
多态：同一个方法，不同子类对象可以产生不同行为，提升程序的扩展性。

3、
序列化作用：将 C# 对象转为 JSON 字符串，用于数据传输、保存。
反序列化作用：将 JSON 字符串还原为 C# 对象，方便程序操作数据。

序列化核心代码：
string json = JsonConvert.SerializeObject(obj);

反序列化核心代码：
var i = JsonConvert.DeserializeObject<T>(json);
